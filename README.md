# 敏敏封面工作室

把你的文字和照片，做成有表达的中文大字封面。

**v1.0.1** · [国内安装页](https://tools.minmin11538.cn/covers/) · [看看 57 张封面样例](https://tools.minmin11538.cn/covers/assets/style-wall/index.html) · [完整安装包](https://github.com/mingminwang962-eng/minmin-cover-studio/releases/latest)

## 交给你的 Agent

复制这句话，发给能联网、读取本机文件并使用图片生成工具的 Agent：

> 请打开 https://tools.minmin11538.cn/covers/，读取 install.md 和 release.json，下载并校验敏敏封面工作室完整包。网页读取失败时使用命令行 HTTPS 获取这两个文件。读取包内 SKILL.md 和 INSTALL.md，由你完成依赖检查与安装，优先复用已有生图能力。根据我提供的文字和照片制作封面，不问保存位置，照片与封面保存在当前内容对应的文件夹，每次更新照片墙和封面墙。已有安装先保留我的资料与作品。

这是安装到 Agent 中使用的 Skill。网站供看样例、下载和阅读说明；制作在用户自己的 Agent 与生图环境中完成，不是在网页上上传照片在线生图。

## 怎么用

1. 发封面文字和自己的照片；有正文或口播稿可以一起给。
2. 让 Agent 推荐三个方向，直接说“你选”，或打开风格页自己挑。点击“选用并复制”后，把说明粘贴回对话。
3. 生成后拿到封面。照片与作品自动保存在当前内容文件夹内；后续上传、修改都会更新两面墙，旧版本保留。

包内提供 57 张敏敏本人授权公开的完整封面样例，整理成 43 个入口、6 类，首页先展示 14 个代表方向。配色、构图和装饰按本次文字与照片变化，不锁死样图颜色；样例中的人物不是使用者本人。

## 使用条件

- Python 3.9+、Pillow，用于归档、风格页构建和提示词编译；Agent 可按 [INSTALL.md](INSTALL.md) 代为安装。
- 实际生成需要 Agent 的图片生成／编辑工具，或用户自己的 OpenAI API 配置。使用已有原生工具时不要求另开 API。
- 包内不含模型账号或免费生图额度；模型服务费用遵循用户已有服务。网页浏览和下载不要求登录。
- 图片按原文件保存，去重、索引和墙在本地更新。网站不收集照片；生成时所选参考图会交给用户选择的模型服务处理。

## 验证与限制

发行检查覆盖完整包换目录安装、57 张图片哈希、提示词与照片入库、独立内容目录、并发锁、连续生成归档、失败恢复和选择复制交互。OpenAI 适配器用模拟响应验证请求和保存逻辑；真实模型授权、额度、人物保真与最终中文效果，需要在用户自己的环境用真实封面验收。安装检查不会产生付费请求。

平台验证状态见 [VALIDATION.md](VALIDATION.md)；Windows 使用系统文件锁，不再依赖 Unix 专用模块。
