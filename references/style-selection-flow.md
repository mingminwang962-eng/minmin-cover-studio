# 封面风格选择交互

## 三条入口

- **用户说“你定／直接做”**：根据内容与照片选择合适风格，直接制作；默认三张有区别的候选。跳过选款与弹页，不再确认已授权的事。
- **用户要做封面，尚未决定风格**：利用已有内容理解，推荐三个有实质区别的方向。每个方向展示一张已有样例，用一句话说明为什么适合本次表达。提供“用这个／换三种／自己挑／你定直接做”，三张参考图不等于三张新成图，不先为选风格花费生图。
- **用户说“打开风格墙／我自己选／看看其他的”**：直接打开选择页，无需再次确认，也不要求先给标题。用户已有明确选择时直接沿用，不强迫浏览。

推荐显示在对话即可，同时给选择页链接；用户表达看图挑选的意图时，用可用的打开工具打开一次。不要每轮弹页、抢焦点。只有工具确认成功才称已打开；仅返回排队时如实说明。

## 选择页

首页14个代表方向；“全部43种”按6类查看。57张历史样图全部保留，同组样例可切换。首页顺序与展示数只是导航，不限制推荐范围，也不表示用户已认可全部历史成图。

用户选择1—3个方向，可选配色偏好、写一句其他要求，也可以直接交给助手。颜色不随样例锁定，不通过改变缩略图颜色假装已经生成新效果。选择不授权更换人物、服装或背景。

页面只在当前浏览器页中保留选择，不会自动发送聊天消息或调用生图。用户点击卡片“选用并复制”即选定该方向并复制当前已选方向，提示“已复制，请粘贴回对话”；不先进入详情。点击图片仍可看大图和切换样例，详情里的选择按钮同样直接复制。“查看选择说明”仅供可选的配色与备注调整。自动复制失败时才展开文字供手动复制，不误报已复制。用户将复制内容粘贴到当前对话；也可以说“我选好了”，此时助手通过浏览器工具打开页面中的“查看选择说明”，读取可见选择与偏好。不能只凭页面打开、某张图被浏览或默认第一个样例就判定已选。浏览器不可读时请用户粘贴说明；不谎称选择已同步。

## 名称到生成风格

读取 [style-navigation.json](style-navigation.json)：`name` 为展示名，`members` 对应 [style-catalog.json](style-catalog.json) 的原 `id`。旧名称和编号继续接受。明确选了样例时使用对应原ID；只选组名时结合内容和照片选择该组内适合的成员，不额外增加问卷。多成员组保留各自设计特点，不把它们改写成一个通用提示词。

用户选一个方向时，先制作该方向的一张封面，除非明确要求多版；用户选多个方向时，每方向一张。用户要求同一风格多版时，分别使用独立配置和新输出目录编译，每份可用同一个 style_id，不向单份配置塞入重复ID，也不通过换风格凑数。其他生成数量以用户要求为准。

配色偏好与其他要求进入已有的 `design.palette`、`scene` 和必要的 `locked_design`；保留人物自然原色。选了风格仍需做标题含义、画面表达和整体设计判断。历史例图中的人物变化、错误道具与遮字不可复制为要求。

## 带本次推荐打开页面

推荐由助手结合本次内容作判断，页面不根据关键词假装完成内容理解。生成一份配置：

```json
{
  "title": "用户已确认的标题原文",
  "recommendations": [
    {"group": "photo", "reason": "结合本次真实照片和表达写具体理由"},
    {"group": "light", "reason": "说明轻拼贴怎样帮助表达该内容"},
    {"group": "cinema", "reason": "说明氛围方向怎样呼应本次情绪"}
  ]
}
```

以上是格式示例，不是每次固定推荐这三组。`group` 必须来自导航目录；避开用户排除项，也不要给三个近似排版冒充不同方向。

使用 `python3 scripts/build_style_picker.py --recommendations /绝对路径/recommendations.json --output /本轮新目录/风格选择.html`，然后打开生成页面。标题与三条具体理由应完整展示；没有本次内容时只打开通用页，不把首页代表方向称为个性化推荐。页面“换一组推荐”会准备请求文字，须回到对话由助手重新推荐，不自动随机换图。

生成页面需 Python 与 Pillow。编译器只读取本地目录与样例，生成较小预览；不调用模型、不修改原图。通用页面已预先生成，直接打开 `assets/style-wall/index.html`，日常浏览无需重建。
