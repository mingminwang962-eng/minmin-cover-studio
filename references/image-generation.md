# 接入用户自己的生图能力

用户请求制作封面时，先查看当前 Agent 的可用图片生成／编辑工具与已有配置，复用已有能力；没有工具时才考虑 OpenAI API 适配器。风格浏览、照片入库与设计提示词编译不需要模型密钥。不得使用制作者的账号、模型服务、私有 Skill 或照片路径。

## Agent 自带图片工具（优先）

1. 按主 Skill 设计，`asset_library.py --content-dir 当前内容目录 prepare config.json` 编译，读取返回轮次中的 `plan.json` 和 `prompts/{style_id}.txt`。
2. 先实际查看 `reference_path` 指向的用户照片。把完整编译提示词作为生成指令，用户原照片作为图片参考，使用宿主提供的生图工具。工具支持本地路径时传绝对路径；只支持会话图片时仅引用本次用户照片。不能用包内敏敏样例代替用户身份参考。
3. 保留 3:4 构图要求、准确标题和自然彩色人物约束；逐张调用，除非宿主明确支持多图。不同工具的参数不同，先读当前工具说明，不猜造工具名或参数。
4. 工具返回本地图片后，立即调用 `asset_library.py --content-dir 当前内容目录 save-cover 本轮目录 风格ID 返回图片路径`。工具已直接写入计划目标时调用 `sync`。若只有不可下载的展示图，应按宿主合法导出能力取得文件；不能声称它已保存到本地。
5. 用户已授权制作时不反复确认。没有任何可用生图能力时，保留已保存照片和提示词，明确说明缺少生图能力；不要用样例或测试图冒充生成结果。

## OpenAI API 适配器（可选）

当用户已选择使用自己的 OpenAI API 时，包内 `scripts/generate_openai.py` 可以发送参考图与提示词、接收生成结果并自动保存、更新两面墙。环境变量 `OPENAI_API_KEY` 仅存在用户自己的进程环境；`OPENAI_IMAGE_MODEL` 或 `--model` 使用用户已配置的图片模型，失败不静默换模型。不要把密钥写进配置、源码、命令历史或输出。

```sh
python scripts/generate_openai.py --content-dir "/当前内容目录" --run "/当前内容目录/我的封面工作室/封面作品/本轮" --candidate wall-27 --model gpt-image-2
```

示例模型支持 1536×2048（3:4）；已配的其他模型需先核实这一尺寸是否受支持。第一次实际调用前可加 `--dry-run` 校验配置；它不生成、不收费，也不代表远端模型可用。API 费用由用户自己的账号承担；宿主订阅不等同于 API 余额。已有原生生图能力时不要求用户另开 API。

脚本固定调用 OpenAI 官方 HTTPS `images/edits` JSON 接口，不向未知兼容代理发送凭据。只发送本次选用的参考照片与提示词，不上传完整照片集。不自动重试已发出的付费请求；失败先检查原因。成功后保留实际模型与接口返回的 usage 信息（若有），没有返回用量时不编造。收到但尚未归档完成的图片保留在本轮 `received-*.png`，可用 `save-cover` 恢复，无需再次生图。

实现依据：[OpenAI 图片编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)，核对日期 2026-10-24。发行测试包含请求格式、模拟响应、自动入库与失败分支；不替用户真实账号完成远端授权或付费生图验收。
